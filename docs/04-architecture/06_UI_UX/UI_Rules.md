# UI Rules

- Màn hình nghiệp vụ kho ưu tiên thao tác nhanh, bảng rõ, nút xác nhận nổi bật.
- Form có trạng thái loading/disabled khi đang gọi API.
- Lỗi nhập liệu hiển thị gần field.
- Trạng thái phiếu dùng màu thống nhất giữa PC/mobile.
- Màn hình mobile ưu tiên quét/chọn nhanh, font đủ lớn, nút dễ bấm.
- Không để UI quyết định rule nghiệp vụ thay cho SP.
