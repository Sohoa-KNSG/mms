# Glossary

| Thuật ngữ | Mô tả |
|---|---|
| PO | Đơn đặt hàng dùng trong nghiệp vụ nhận hàng |
| Phiếu nhận hàng | Header ghi nhận vật tư nhận từ NCC/nội bộ |
| Batch | Lô tồn kho theo vật tư, số lượng, trạng thái, vị trí |
| Lưu kho | Gán batch/vật tư vào vị trí kệ |
| Soạn hàng | Chuẩn bị vật tư theo phiếu yêu cầu xuất |
| Đề nghị xuất kho | Phiếu yêu cầu xuất vật tư từ đơn vị |
| QC | Kiểm tra chất lượng vật tư |
| Phiếu trả nội bộ | Phiếu đơn vị sản xuất trả vật tư về kho |
| SP | Stored procedure SQL Server xử lý nghiệp vụ |
