# Acceptance Criteria

- 100% screen Power Apps có mapping sang React route.
- 100% entity trong schema Word có file mô tả.
- 100% nghiệp vụ ghi dữ liệu có stored procedure hoặc ADR ngoại lệ.
- Backend không chứa business logic chính.
- Có integration test cho SP nhập kho, xuất kho, trả nội bộ, tồn đầu tháng.
- Có UAT theo từng nhóm nghiệp vụ.
