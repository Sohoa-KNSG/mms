# Stakeholder & Roles

| Role | Nghiệp vụ chính |
|---|---|
| Nhân viên nhận hàng | Tạm nhận, nhận hàng PO/không PO/nội bộ |
| Thủ kho nhập | Nhập kho, tách batch, in tem, lưu kho |
| QC | Cấu hình kiểm, lập phiếu kiểm, đánh giá vật tư |
| Thủ kho xuất | Soạn hàng, xuất kho, xuất trực tiếp |
| Đơn vị yêu cầu/sản xuất | Đề nghị xuất, trả vật tư nội bộ |
| Quản lý/duyệt | Phê duyệt đề nghị, theo dõi trạng thái |
| Admin | Role, screen, user |
| IT/DBA | API host, stored procedure, deployment, audit |
