# Project Charter

## Tên dự án

Chuyển đổi toàn bộ ứng dụng kho vật tư từ Power Apps sang React.

## Mục tiêu

- Bao phủ đầy đủ nghiệp vụ hiện có trong hai app Power Apps.
- Chuẩn hóa UI/UX, source code, API contract và test.
- Bảo toàn dữ liệu SQL Server MMS hiện hữu.
- Đưa logic nghiệp vụ về SQL stored procedure, backend không xử lý rule nghiệp vụ chính.

## Phạm vi nghiệp vụ

- Đăng nhập, phân quyền.
- Nhận hàng PO, không PO, nội bộ và tạm nhận.
- Nhập kho, cập nhật PO, tách batch, in tem.
- QC cấu hình, phiếu kiểm, đánh giá, lịch sử.
- Tồn kho, lưu kho, vị trí kệ, kiểm kê.
- Đề nghị xuất kho, phê duyệt, soạn hàng, xuất kho.
- Phiếu trả/nhập nội bộ.
- Báo cáo và lịch sử giao dịch.
